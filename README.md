# Detect-Phishing-URLs-Before-They-Detect-You
Create a modern AI-powered cybersecurity web application named "AI-Based MITM Detection System" with a professional dark Security Operations Center (SOC) interface. The application detects Man-in-the-Middle (MITM) attacks by analyzing network traffic using Machine Learning.

Use React.js + Tailwind CSS for the frontend, Flask for the backend API, Scikit-learn (Random Forest Classifier) for ML, Recharts for visualizations, and Lucide React icons. Apply a black background, neon blue accents, green secure indicators, red threat alerts, glassmorphism cards, smooth animations, and a fully responsive layout.

Pages & Features
Home: Hero section with cybersecurity illustration, title “AI-Based MITM Detection System”, subtitle “Detect Network Attacks Using Machine Learning Before Data Is Compromised”, buttons (Start Detection, View Dashboard, Generate Report), and statistic cards (50,000+ Packets Analyzed, 95% Accuracy, 24 Threats Found, Network Status: Secure).
SOC Dashboard: Live monitoring with cards showing Current Traffic, Connected Devices, Packets/sec, Threat Level, plus real-time traffic graphs, packet activity charts, and network timeline.
Packet Analysis: Interactive table displaying Packet ID, Source IP, Destination IP, Protocol, Packet Size, and Status. Include a feature extraction panel showing Packet Length, Protocol Type, Source Frequency, Destination Frequency, and Connection Duration.
ML Detection: AI prediction screen using Random Forest Classifier. Inputs include Packet Size, Protocol, IP Changes, and Traffic Rate. Display predictions such as Normal Traffic (8% Attack Risk) or ⚠ MITM Attack Detected (94% Probability) with an animated AI scanning effect.
Attack Analysis: Cards displaying Attack Type (ARP Spoofing), Source IP, Risk Level, Confidence Score, and a threat history chart with attack trends.
Cyber AI Assistant: Chat interface where users ask security questions (e.g., “Why was this traffic detected as malicious?”). AI explains abnormal ARP behavior, packet flow anomalies, and ML reasoning. Include typing animation.
Report Generation: Dashboard summarizing Date & Time, Packets Scanned, Normal Traffic, Suspicious Traffic, and Attack Probability with a functional Export PDF Report button.
Admin Settings: Display Dataset (Wireshark Network Dataset
